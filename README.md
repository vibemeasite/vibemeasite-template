# VibeMeASite site template

This is the website template that VibeMeASite uses to create a new site
every time someone builds a site through the VibeMeASite chat assistant.

You don't need to edit this repository directly — sites built through
VibeMeASite are managed entirely through chat. This repo exists so each
site can be deployed automatically.

Built with [Next.js](https://nextjs.org).
